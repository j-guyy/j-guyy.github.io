# Flags

Small flags for the US and World travel tables, rendered by
`scripts/build-flags.mjs` (42×28 PNG, shown at 21×14).

- Countries (`<iso>.png`): [flag-icons](https://github.com/lipis/flag-icons) 7.6.0, MIT License, © 2013 Panayiotis Lipiridis.
- US states (`us-<postal code>.png`): [us-state-flags](https://www.npmjs.com/package/us-state-flags) 1.0.7, ISC License. US state flags are in the public domain.
